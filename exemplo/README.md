# Exemplo de registro

Política de privacidade e termos de uso **anonimizados**, no registro institucional brasileiro. Servem de referência de **abertura, ordem das seções e tom**. Não são o documento a copiar para software livre: a matéria (modo A/B, ausência de garantia, dado só no dispositivo) continua a do quadro de fatos.

Placeholders: `[ORGANIZAÇÃO]`, `[CNPJ]`, `[ENDEREÇO]`, `[CIDADE]`, `[UF]`, `[CEP]`, `[E-MAIL]`, `[SÍTIO]`, `[GRUPO]`, `[COMARCA]`, `[DATA]`, `[ANO]`, `[QUALIFICAÇÃO JURÍDICA]`.
